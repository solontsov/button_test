# Button Test Skill

When the user asks to "open button test", invoke the UI runner tool using `scripts/index.html`.

This skill presents two interactive buttons:
1. "Tell a Joke" - Generates a request for a joke.
2. "Explain a Random CSS Rule" - Generates a request for a CSS explanation.

Follow the instructions or parameters returned by the interactive HTML interface.
